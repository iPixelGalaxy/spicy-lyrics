# Enable DevTools

Some Spicy Lyrics window features need Spotify DevTools to be enabled before they can open a separate Spotify window.

## Spicetify CLI

Run:

```powershell
spicetify enable-devtools
```

Then restart Spotify.

## Spotify Plus

You can also use [Spotify Plus](https://github.com/iPixelGalaxy/spotify-plus), another plugin that can help keep DevTools enabled semi-permanently.

Install Spotify Plus, open its settings, then toggle this setting on and off a few times while DevTools are enabled:

> Toggle me a few times while dev tools are enabled to keep them on

After that, restart Spotify and check whether DevTools remain enabled.
